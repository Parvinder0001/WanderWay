# Contributing to WanderWay

Thank you for your interest in contributing to WanderWay!

WanderWay is a travel agency website developed using HTML, CSS, and JavaScript. We welcome contributions that improve the design, functionality, and user experience.

## How to Contribute

1. Fork the repository.
2. Clone your forked repository.
3. Create a new feature branch.
4. Make your changes.
5. Test your changes in a web browser.
6. Commit your changes with a meaningful commit message.
7. Push your branch to GitHub.
8. Open a Pull Request.

## Branch Naming

Use meaningful branch names, such as:

- `feature/destination-search`
- `feature/dark-mode`
- `fix/booking-validation`

## Commit Message Guidelines

Write clear and meaningful commit messages.

Examples:

- `Add destination search feature`
- `Implement dark mode`
- `Improve booking form validation`
- `Update website styling`

## Coding Guidelines

- Write clean and readable HTML, CSS, and JavaScript.
- Use meaningful variable and function names.
- Avoid unnecessary duplicate code.
- Test new features before submitting a Pull Request.
- Do not commit unnecessary files.

## Reporting Issues

If you find a bug or have a suggestion, open an issue in the GitHub repository with a clear description.

Thank you for contributing to WanderWay!
